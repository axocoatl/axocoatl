<Aside type="caution">
This page is a selected command overview, not a generated reference. Run
`axocoatl --help` and `axocoatl <subcommand> --help` against your installed
version for the authoritative flags and subcommands.
</Aside>

## Lifecycle

| Command | Purpose |
|---------|---------|
| `axocoatl onboard` | Interactive setup wizard. Picks a provider, scaffolds a project. |
| `axocoatl doctor` | Environment health check (Rust, config, Ollama, podman, data dir, daemon reachable). |
| `axocoatl init <name>` | Scaffold a project non-interactively. Drops `axocoatl.yaml`, `.env.example`, `data/`. |
| `axocoatl validate <config>` | Validate a config file without booting. |
| `axocoatl dev` | Start the daemon, IPC, and browser app for local development. |
| `axocoatl serve` | Start the production daemon, IPC, and HTTP/browser app. This is also the service-install runtime. |

## Service (always-on)

| Command | Purpose |
|---------|---------|
| `axocoatl service install` | Install the daemon as a system service (systemd on Linux, launchd on macOS). |
| `axocoatl service start` | Start the installed service. |
| `axocoatl service stop` | Stop it. |
| `axocoatl service status` | Show whether the service is installed and running. |
| `axocoatl service uninstall` | Remove the service unit. |

## Chat

| Command | Purpose |
|---------|---------|
| `axocoatl chat -a <agent>` | Legacy interactive console backed by the configured agent's global actor transcript. |

<Aside type="caution" title="`chat --session` is not a workspace Session">
The CLI currently accepts `--session`, but the daemon does not use that value to
select or restore an isolated transcript. Different values still reach the same
agent-global actor state. Use the workbench at `/` or `axocoatl session …` when
workspace Session identity matters.
</Aside>

## Workflows

| Command | Purpose |
|---------|---------|
| `axocoatl workflow list` | Compatibility view of manual records in the canonical Automation store. |
| `axocoatl workflow run <id> -i "<input>"` | Run one canonical manual Automation. |

## Sessions

| Command | Purpose |
|---------|---------|
| `axocoatl session new <dir> --agent <agent>` | Start a new session in a directory. |
| `axocoatl session list` | List active sessions. |
| `axocoatl session exec <id> "<input>"` | Send an instruction to a directory session. |
| `axocoatl session close <id>` | Close a directory session. |

## Agents

| Command | Purpose |
|---------|---------|
| `axocoatl agents list` | List every agent. |
| `axocoatl agents status` | Per-agent status. |
| `axocoatl agents restart <id>` | Restart one agent under the supervisor. |

## Tokens

| Command | Purpose |
|---------|---------|
| `axocoatl tokens report` | Per-agent token usage since boot. |

## Skills

| Command | Purpose |
|---------|---------|
| `axocoatl skills list` | List configured Skills. |
| `axocoatl skills run <name> [key=value …]` | Run a Skill with optional parameters. |

## MCP

| Command | Purpose |
|---------|---------|
| `axocoatl mcp servers` | List connected MCP servers. |
| `axocoatl mcp tools` | List every tool exposed by every connected MCP server. |
| `axocoatl mcp serve` | Expose configured agents as MCP tools over stdio. |

## Benchmarks

| Command | Purpose |
|---------|---------|
| `axocoatl benchmark [token|routing|isolation|actor|all]` | Run the selected local benchmark harness. |

## Help

| Command | Purpose |
|---------|---------|
| `axocoatl --help` | List all subcommands. |
| `axocoatl <subcommand> --help` | Help for a specific subcommand. |
| `axocoatl --version` | Print the binary version. |
