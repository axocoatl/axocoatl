The daemon exposes the browser app, REST endpoints, and a WebSocket on port
8080 by default. The tables below cover the main integration surfaces; they
are not an exhaustive generated route reference.

<Aside type="caution">
This page is hand-written. The router in `axocoatl-server/src/lib.rs` and the
request/response types in the current source are authoritative for every
route and field.
</Aside>

## Health

| Method | Path | Returns |
|--------|------|---------|
| GET | `/health` | `{ status, agents }` — overall daemon health + agent count. |
| GET | `/health/ready` | 200 if at least one agent is spawned; else 503. |
| GET | `/health/live` | Always 200 — used by load balancers. |
| GET | `/api/llm-health` | `{ ollama: { reachable, base_url, missing_models } }` — checked by the app's first-run toast. |

## Agents

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/agents` | List every agent in the config with provider/model/status. |
| GET | `/api/agents/{id}/status` | Just the status string. |
| POST | `/api/agents/{id}/execute` | Send the agent a single input; await the full output. Body `{ input, system_override?, model_override?, stateless? }`. The overrides run a prompt/model variant for that one call (and imply `stateless`); set `stateless: true` to run a call in isolation from the agent's session/checkpoint even without an override — e.g. scoring an agent over independent inputs. |
| POST | `/api/agents/{id}/restart` | Restart the actor under the supervisor; memory survives. |
| PATCH | `/api/agents/{id}` | Update model / system prompt at runtime. |

## Workflows + automations

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/workflows` | Compatibility view of manual records in the canonical Automation store. |
| POST | `/api/workflows/{id}/execute` | Run a canonical manual Automation; body `{ input }`. |
| GET | `/api/automations` | List records in the canonical automation store, which also drives live schedule, event, and Skill triggers. Legacy YAML is a first-boot seed only. |
| POST | `/api/automations` | Create a canonical Automation. Automatic triggers become live without a restart. |
| PUT/PATCH | `/api/automations/{id}` | Replace a canonical Automation; trigger edits affect subsequent dispatch. |
| DELETE | `/api/automations/{id}` | Delete a canonical Automation and remove it from subsequent trigger matching. |
| POST | `/api/automations/{id}/run` | Fire an automation by id. |
| GET | `/api/schedules` | Compatibility projection of scheduled canonical automations, including next/last run and error state. |
| PATCH | `/api/schedules/{id}` | Update enabled state, cadence, or input on the canonical automation record. |
| POST | `/api/schedules/{id}/run` | Run the canonical scheduled automation immediately. |
| GET | `/api/proactive` | Compatibility projection of canonical event-, Skill-, and legacy proactive-schedule automations. |

Settings can create, inspect, edit, enable, disable, and run Automation records.
Its **+ Automation** flow collects the record and trigger basics, then sends a
valid Input → Agent starter DAG to `POST /api/automations`. The endpoint remains
available for programmatic creation. Legacy YAML is a one-time seed only when no
canonical store file exists.

## Attempts

One session can have one unresolved attempt set. The daemon rejects another set or a
normal session turn until the current set is kept or discarded. Set-scoped attempt
endpoints return `409` for lifecycle conflicts. Status, diff, Routes, Checks, Judge,
cost, Keep, and Discard carry `attempt_set_id`; a stale id returns `409` instead of
touching the current set. `results` intentionally reads whichever set is current.

Attempt execution currently requires a single-agent session and
`sandbox.backend: podman`. Start rejects multi-agent and E2B sessions. Each attempt
runs in an independent no-origin Git clone mounted alone in a dedicated Podman
container; it does not share the primary repository's Git directory or the session
container.

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/api/sessions/{id}/variants` | Start several local-Podman attempts. Body `{ task?, input, n?, lanes? }`; `input` is the effective instruction and `task` preserves the original request. Returns the durable attempt set. |
| GET | `/api/sessions/{id}/variants/results` | Read the durable current set, resolved attempt identities, lifecycle states, natural-language outputs, Checks verdicts, usage/cost records, and Judgment. This read does not start a closed session's sandbox. |
| GET | `/api/sessions/{id}/variants/status?attempt_set_id=…` | Read each attempt's changed files. |
| GET | `/api/sessions/{id}/variants/trajectories?attempt_set_id=…&baseline=0` | Align the attempts' recorded Routes. |
| GET | `/api/sessions/{id}/variants/diff?attempt_set_id=…&index=0&path=…` | Read one file's before/after content for one attempt. |
| POST | `/api/sessions/{id}/variants/verify` | Run Checks after every attempt is terminal. Body `{ attempt_set_id, check }`; an empty `check` uses the session's configured check command. |
| POST | `/api/sessions/{id}/variants/judge` | Rank the passing, non-empty survivors. Body `{ attempt_set_id, provider, model? }`. |
| POST | `/api/sessions/{id}/variants/adopt` | Keep one completed attempt whose Check passed with a non-empty change. Body `{ attempt_set_id, index }`; applies its delta without committing and resumes the same Keep transaction after a partial failure. |
| POST | `/api/sessions/{id}/variants/discard` | Cancel/join and remove the set. Body `{ attempt_set_id }`. Rejected after Keep enters its apply phase; retry Keep instead. |
| POST | `/api/sessions/{id}/variants/plan` | Produce a reviewable execution plan. Body `{ task, provider, model? }`. |
| GET | `/api/variants/probe?provider=…&models=…` | Check whether selected models return structured tool calls. |
| GET | `/api/sessions/{id}/variants/cost?attempt_set_id=…&baseline=…&baseline_provider=…` | Price recorded usage and an explicitly selected counterfactual. Pass `baseline_provider` to disambiguate local from remote models. |

`total_usd` is complete only when `actual_cost_known` is true; otherwise it is the
subtotal for attempts with known prices. `baseline_usd` has the independent
`baseline_cost_known` flag. Ollama attempts are known-zero, while a remote model with
no configured price remains unknown. `all_local` is true only after every attempt has
usage and every persisted attempt provider is Ollama. These totals cover attempt
execution; optional Plan first and Judge provider calls are not included.

Keep persists `applying`, `applied`, and `transcript_recorded` phases. Retrying the
same `{ attempt_set_id, index }` resumes the unfinished phase and cleanup. A different
index conflicts once Keep begins. The chosen task and answer are appended exactly once
to the single-agent session's checkpoint transcript.

## Live WebSocket

`/ws` is bidirectional. Frames are JSON with a `kind` discriminator. The one
app uses `snapshot`, `event`, `token`, `reasoning`, `tool-call`,
`session-start`, `session-done`, `session-error`, and the
`mcp-approval-required` / `mcp-approval-resolved` pair to restore and observe
session work. An `event` frame is a typed runtime notification used for scoped
run and Agent-graph state; the retired Studio event timeline is not a current
browser surface.

The server also retains `workflow-done` / `workflow-error` and the
`chat-start` / `chat-token` / `chat-tool-start` / `chat-tool-result` /
`chat-done` / `chat-stopped` / `chat-error` frame family for compatibility
clients. Likewise, client-to-server commands include the active `session`,
`mcp-approve`, and `ping` commands plus retained `run-workflow`, `chat-turn`,
and `chat-stop` compatibility commands. Those retained protocol paths do not
make Studio, lightweight Chat, or cross-chat Files browser destinations in the
one app.

## Static assets

- `/` — the one-app HTML.
- `/ui/{*file}` — embedded native UI modules and shared styles.
- `/brand/{file}` — canonical brand assets (`mark.png`, `wordmark.png`, `favicon.png`, `colors.json`).
- `/lattice/{file}` — the `@axocoatl/lattice` Web Component source.
- `/vendor/{*file}` — vendored libs (Monaco, highlight.js, xterm, codicons).
