Axocoatl is a **local-first coding workbench** backed by a durable Rust agent
runtime. Work in one folder-anchored session, ask one agent or explore several
ways, run the repository's checks, compare what happened, and keep one inspectable
result. The runtime has no Axocoatl telemetry; model providers, integrations,
and remote isolation are the outbound paths you choose.

## What's the wedge?

The agent-tooling industry has a theater problem. Mac mini farms, glowing
terminals, demo videos. The optics have eaten the output. Axocoatl is for
the opposite kind of team: the one with actual work to ship.

The workbench is backed by a **runtime**, not a framework you must assemble into
a product. One binary runs on your box, supervises agents, persists their state
through crashes and restarts, and records the session activity, attempt Routes,
Checks, and git changes it can observe. The LLM is your choice. Local Podman is
the default session sandbox; a remote sandbox is used only when you choose it.
