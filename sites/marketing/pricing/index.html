What can cost money

Your infrastructure choices.

For Ways, Axocoatl records model usage and known provider cost where pricing is configured. It does not pretend unknown remote pricing is free.

Models

Provider usage

Within Ways, Ollama at a configured loopback endpoint has a known-zero model API charge. Non-loopback Ollama uses its configured model price or remains unknown.

Sandboxes

Compute

Rootless Podman uses your local machine. E2B Cloud remote compute is optional and uses your E2B account.

Extensions

External services

MCP servers, webhooks, and other integrations may have their own usage or hosting costs.

Cost visibility

See the model cost of Ways.

Hosted model calls and optional remote services use your accounts. For each Way, Axocoatl records provider, model, token counts, duration, and configured model price when known; unknown remote pricing is marked incomplete rather than presented as zero.

Every Way is a separate model execution. Plan first, model checks, and Judge may incur additional provider charges; Axocoatl shows those calls separately instead of attributing shared review work to one Way. A failed call without terminal usage remains an incomplete lower bound, not a zero. Use several Ways when the decision justifies the extra compute.
