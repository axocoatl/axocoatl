Axocoatl is the local-first coding workbench for real repositories. One durable Session keeps conversation, repository tools, execution evidence, and Git review together. Workspace knowledge retains the decisions, sources, and findings the next Session needs. Start with one Agent, or select an autonomous multi-Agent team and keep its coordination map with the turn. When a decision needs evidence, compare several checked Ways from the same task and snapshot, then Keep one result as uncommitted Git changes.

One result, several roles

Keep the coordination.

Select an autonomous multi-Agent Lattice team or assemble an autonomous Custom team inside the Session. For native work, review its configuration and explicit limits in Team & budget. Axocoatl retains the accepted dependencies for that Turn. Roots start from the request; each downstream Agent receives the request plus only its latest direct-parent handoffs.

Independent branches continue when they can. Dependent work blocks honestly. Approved revisions retain the earlier generation and the affected route before verification. The graph, handoffs, generations, failures, and final state remain attached to the conversation. Native Coordinators create distinct Worker activations from approved templates and limits in the same recorded turn.

When the decision needs evidence

Compare real Ways.

One Agent or a configured team remains the direct path. When the implementation is genuinely uncertain, the same Session can give one task and repository snapshot to several Agent/model pairs. Each Way works in an isolated checkout and sandbox.

Run the same repository Check. Compare Outcome, Route, available diff, cost, and an optional Judge while the decision is open. Keep one passing, non-empty result for Git review, or finish without keeping any of them. Native History retains the bounded decision after cleanup under explicit storage limits.

The smaller front door

One executable. Your browser.

Install one axocoatl executable. It starts the local Rust daemon and serves the workbench to the browser you already use. The workbench assets are embedded, so using Axocoatl requires no separate frontend install or bundled browser runtime. Podman remains the local sandbox requirement for repository Sessions.

Configure Axocoatl once for the current OS user; onboarding creates no project. Remote providers, integrations, downloads, and E2B Cloud are explicit network paths. Local-first is the default, not an offline guarantee.
