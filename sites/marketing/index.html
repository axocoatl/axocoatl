What's different

A workbench backed by a runtime.

Most agent tooling optimizes for the aesthetic of AI work. We optimize for the unglamorous reality: the work that ships.

One persistent session

Chat is the spine. Files, editor, terminal, browser, activity, attempts, comparison, git, and agent graph open around the work.

Several real attempts

Choose the agent and model for each way. Run repository checks, compare Outcome and Route, keep one result, and inspect its git changes.

Yours by default

Your infrastructure choice, zero Axocoatl telemetry, one binary. Podman is local by default; providers and remote isolation are the ones you choose.

Concept · 30 seconds

Explicit work. Shared events.

Manual Automations run as explicit DAGs. The lattice is the typed event feed shared by Skills, event-triggered Automations, webhooks, and Activity. Those are separate execution and notification paths.

Legacy workflows: YAML can seed a manual Automation once; its depends_on declarations become graph edges. The workflow command is a compatibility route into that same canonical Automation executor.

How it works →
axocoatl.yaml · first-boot seed 
agents:
  - id: researcher
    provider: ollama
    model: llama3.2
    depends_on: []
  - id: summarizer
    provider: ollama
    model: llama3.2
    depends_on: [researcher]   # explicit Automation edge

workflows:
  - id: research-and-summarize
    agents: [researcher, summarizer]
    entry_point: researcher
Concept · 30 seconds

Agents that actually remember.

Most agents are stateless. Axocoatl gives each one real memory: a live session, a daily log it can read back by date, and a neural recall tier whose inference runs on-device after its model weights are downloaded. The agent's selected provider and optional integrations may still be remote.

The part that matters most is core memory: small, agent-editable blocks the agent curates as it works, rendered into its context every turn. While it sits idle, a background pass promotes durable facts up into those blocks. Understanding compounds instead of resetting every run.

The one app

Build in the session.

Authorize a directory and start or resume a session. Chat stays in the main area while modules open around it. Every file read, write, command, check, and attempt streams back to the same work surface.

Sandboxed by default

Podman is the local default, bound to your folder. The agent sees your code and you see every file it touches. An E2B-compatible remote sandbox is an explicit per-session choice.

One answer or several ways

Send normally for one solution. Explore several ways when you want alternatives from different agents and models, then verify and keep one.

Real tools, real outputs

Read, write, edit, glob, grep. Run commands. Spawn background processes. Open PTY terminals. Every tool call shows up as a chip in the Activity pane with the output collapsible inline.

Install

One release binary.

Prebuilt binaries for macOS (Apple Silicon and Intel) and Linux (x86_64 and aarch64). Releases include SHA-256 checksum files; the installer verifies one when it can retrieve it.

curl -fsSL https://axocoatl.ai/install.sh | sh

Prefer Cargo? cargo install axocoatl-cli. See the install page for prebuilt, Cargo, from-source, and WSL2 paths.
