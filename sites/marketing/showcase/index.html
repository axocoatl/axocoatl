A complete record

The work stays on the record.

Each accepted Turn records its request and context before the Agent starts, and keeps its output, tool activity, and final state in the Session, beside Files, Terminal, Preview, and Git.

01 · Ordinary path

One Agent, one repository job

Start with a concrete behavior and a repository check. The Agent diagnoses the defect, edits the implementation, runs the command, and leaves the result for review without committing.

02 · Work units

Workspace, Session, Turn

An authorized Workspace groups named Sessions. Returning to one restores its accepted Turn instead of creating another disposable conversation.

03 · Continuity

Reconnect to the exact Turn

Accepted work does not depend on one browser connection. Reload reconnects to the active Turn, and Stop leaves an honest cancelled state in History.

Isolation built in

Tools run in a sandbox. One Agent writes.

Every Session's repository tools run in a rootless Podman container. Read-only helpers get no file-writing tools, and the kernel blocks their shell from writing, creating, renaming or deleting repository files and from opening TCP connections (Landlock, Linux 6.7 or later); otherwise they get no shell.

04 · Sandbox

Terminal and Preview share the checkout

The Terminal identifies the Session's local Podman sandbox, runs the repository contract, and serves the application opened in Preview through an explicitly published port.

05 · One writer

A lead with read-only helpers

The film follows the default team: Lead owns the change and is the only Agent that edits files. It delegates a question to Scout and a review of its diff to Reviewer, both read-only helpers whose limits were approved in Team and budget, and the required check runs before the Turn completes. It does not show required review. This is one team result, not several competing Ways, and not a claim that the team beats one Agent.

Any model

Choose the model and the approach.

Each Agent has its own provider and model, local through Ollama or hosted through OpenRouter. When an implementation decision needs independent evidence, several Agent/model pairs can attempt it; Git remains the final handoff.

06 · Decision mode

Compare independent Ways

Every Way receives the same task and Check command. While the decision is unresolved, Axocoatl keeps completion states, Outcome, Route, changed files, and Check evidence separate. Judge is optional; the film follows Keep into the uncommitted result. Native Sessions also retain bounded decision evidence after cleanup under explicit storage limits; the film does not demonstrate that History flow.

07 · Repository ownership

Keep is not commit

Keep returns one checked result to the primary Session checkout. Source Control → Last turn filters the current Git diff to paths attributed to the kept Turn before any optional staging or commit; it is not a frozen per-turn diff.

The runtime underneath

Configuration and durable machinery.

Agents, Skills, MCP servers, and Automations live in Settings. Configured Automations retain their own event and Interrupt state. Native Session knowledge and execution evidence remain separately inspectable.

08 · Settings

A provider and model per Agent

Agents and their provider/model assignments, Skills, MCP servers, and Automations stay in Settings rather than becoming peer destinations beside the Session. Configure Axocoatl once for the current OS user; explicit project-local YAML remains an advanced operator path.

09 · Typed events

A Skill can trigger an Automation

The Skill publishes its declared event. The event feed carries it to configured observers, and the matching Automation trigger starts an inspectable durable run.

10 · MCP approval

A new permission pauses the call

With no matching saved decision, a compatibility Session pauses before a deterministic local MCP tool executes. Deny prevents dispatch; Allow once returns bounded tool evidence and the final answer to History. Native Session turns do not expose this configured registry.

11 · Workspace knowledge

Keep a decision across Sessions

A source-linked note and its backlink survive restart. A native Agent in a separate Session retrieves the exact accepted revision, while each conversation keeps its own History.

12 · Operator judgment

Pause and resume an Automation

A top-level Interrupt parks the run with upstream node state intact. Operator guidance resumes from that checkpoint and the completed Result remains in run history.
